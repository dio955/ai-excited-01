# A whale breaching through a sea of clouds

A humpback whale, huge and unhurried, breaks through a sea of clouds above a small town at dusk. The clouds roll like an ocean around the rooftops below, lit amber and rose by the setting sun, while the whale hangs in the evening sky as if the sky itself were water. It is the kind of sight that stops you mid-step and makes you look up — the impossible, made ordinary for one evening.

This repository is an entry for the [ai-excited-01 bounty on make.fun](https://make.fun/bounty/ai-excited-01), where an AI judge picks the image that excites it most. The entry program is `main.ts`: run it with `node main.ts` and it copies `entry.png` to `/output/entry.png`, byte for byte, every time — deterministic, no network, nothing else needed.
